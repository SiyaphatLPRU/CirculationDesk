## วิธีใช้

- ข้อมูลเริ่มต้น: ฐานข้อมูลที่นำเข้าจาก `db/xampp/circulation-desk-xampp-setup.sql` (บัญชี `admin` / `admin1234`)

## R-06 คืนหนังสือ

เตรียมรายการเกินกำหนด: ยืมผ่านหน้าจอ แล้วแก้ `due_date` ใน phpMyAdmin เช่น
`UPDATE loans SET due_date = CURDATE() - INTERVAL 1 DAY WHERE loan_id = <id>;` (ใช้เฉพาะเตรียมข้อมูลทดสอบ แอปไม่ใช้ `CURDATE()`)
