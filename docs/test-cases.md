## วิธีใช้

- ข้อมูลเริ่มต้น: ฐานข้อมูลที่นำเข้าจาก `db/xampp/circulation-desk-xampp-setup.sql` (บัญชี `admin` / `admin1234`)
- URL ในตัวอย่างอ้างจาก base ของระบบ เช่น `http://localhost:8000/` (php -S) หรือ `http://localhost/Circulation-Desk/src/public/`
- คอลัมน์ "ผล" ให้ผู้ทดสอบกรอก `ผ่าน` / `ไม่ผ่าน` พร้อมวันที่
- กรณีทดสอบอัตโนมัติของบริการอยู่ใน `tests/` (รันด้วย `php tests/run.php`) อ้างรหัส `AT-xx` ในตารางท้ายเอกสาร

| TC-03 | R-01 | กรอกชื่อผู้ใช้ที่ไม่มีในระบบ | ข้อความเดียวกับ TC-02 ทุกตัวอักษร (ไม่บอกว่าผิดช่องใด) | |

## บันทึกการทดสอบของผู้พัฒนา

ผู้พัฒนารันกรณีต่อไปนี้แล้วบน XAMPP จริง (Apache + MariaDB 10.11, PHP 8.3) ผ่านคำขอ HTTP อัตโนมัติ (PowerShell `Invoke-WebRequest`) ผลผ่านทั้งหมด:
TC-01 ถึง TC-10

กรณีที่ต้องให้ผู้สอนรันเอง: TC-11 (ต้องหยุดบริการฐานข้อมูล), การตรวจหน้าจอด้วยตา (การจัดวางบนมือถือ/เดสก์ท็อป)
