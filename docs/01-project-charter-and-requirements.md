## 1. วัตถุประสงค์

พัฒนาระบบเว็บสำหรับเจ้าหน้าที่ห้องสมุดขนาดเล็ก ใช้บันทึกการยืม-คืนหนังสือ ตรวจรายการเกินกำหนด และออกรายงาน
และใช้เป็นต้นแบบให้นักศึกษาเห็นกระบวนการ SCM จริง (การระบุ SCI, การควบคุมการเปลี่ยนแปลง, การบันทึกสถานะ, Traceability)

## 2. ขอบเขต

- ผู้ใช้ระบบคือ **เจ้าหน้าที่** เท่านั้น (สมาชิกไม่ได้เข้าระบบเอง)
- ไม่รวม: การจองหนังสือ, การชำระค่าปรับออนไลน์, หน้าจัดการบัญชีเจ้าหน้าที่ (เพิ่มผ่าน SQL)
- เทคโนโลยี: PHP 8.2 (ไม่ใช้ framework), MySQL 8.0 / MariaDB (XAMPP), PDO

## 3. กฎธุรกิจ

| รหัส | กฎ |
|---|---|
| BR-01 | ระยะเวลายืม 7 วันนับจากวันที่ยืม |
| BR-02 | สมาชิกหนึ่งคนยืมค้างได้ไม่เกิน 3 เล่ม |
| BR-03 | ค่าปรับ 5 บาท ต่อวัน ต่อเล่ม เมื่อคืนเกินกำหนด |
| BR-04 | สมาชิกสถานะ `suspended` ยืมไม่ได้ |

## 4. ความต้องการเชิงหน้าที่

| รหัส | ความต้องการ | รายละเอียด |
|---|---|---|
| R-01 | เข้าสู่ระบบเจ้าหน้าที่ | เข้าสู่ระบบด้วยชื่อผู้ใช้/รหัสผ่าน (เก็บแบบ hash) ออกจากระบบได้ หน้าอื่นทั้งหมดต้องเข้าสู่ระบบก่อน |
| R-02 | จัดการข้อมูลหนังสือและหมวดหมู่ | เพิ่ม แก้ไข ลบ ดูรายการหนังสือและหมวดหมู่ |
| R-03 | จัดการข้อมูลสมาชิก | เพิ่ม แก้ไข เปลี่ยนสถานะ active/suspended |
| R-04 | ค้นหาและดูสถานะหนังสือ | ค้นจากชื่อ ผู้แต่ง ISBN กรองตามหมวดหมู่ เห็นจำนวนคงเหลือ |
| R-05 | ยืมหนังสือ | บันทึกการยืมตาม BR-01, BR-02, BR-04 |
| R-06 | คืนหนังสือ | บันทึกการคืนและคำนวณค่าปรับตาม BR-03 |
| R-07 | ตรวจรายการเกินกำหนด | แสดงรายการที่ยังไม่คืนและเลยกำหนด พร้อมค่าปรับสะสม |
| R-08 | รายงานประวัติการยืม-คืน | กรองตามสมาชิกและช่วงวันที่ สรุปจำนวนและค่าปรับรวม |

## 5. ความต้องการที่ไม่ใช่เชิงหน้าที่

- ความปลอดภัย: prepared statements, escape output, CSRF token, session cookie แบบ httponly
- รันได้ทั้ง XAMPP และ Docker โดยไม่แก้โค้ด
- หน้าจอภาษาไทย ใช้งานได้บนมือถือและเดสก์ท็อป
